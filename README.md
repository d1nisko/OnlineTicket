# OnlineTicket

Система онлайн-замовлення квитків на транспорт.

## Опис

Веб-застосунок для пошуку рейсів, бронювання та оплати квитків. Реалізовано як навчальний проєкт у курсі "Технології розробки програмного забезпечення".

## Технології

- HTML5
- CSS3
- JavaScript (Vanilla)

## Структура проєкту

```
OnlineTicket/
├── assets/
│   ├── css/
│   │   └── style.css       # стилі застосунку
│   └── images/             # зображення
├── js/
│   └── app.js              # клієнтська логіка
├── views/                  # додаткові HTML-сторінки
├── index.html              # точка входу
├── .gitignore              # ігноровані файли
└── README.md               # цей файл
```

## Запуск

Відкрити файл `index.html` у будь-якому сучасному браузері. Жодних додаткових залежностей не потрібно.
